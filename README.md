# My Blog Project

A blog application built with Laravel.

## Features

- User registration and login
- Create, edit, and delete posts
- Comment on posts
- Image upload
- Proper authorization. User can only edit,delete their own post or comments. 

## Technologies Used

- Laravel
- PHP
- MySQL
- Bootstrap

## Installation

```
git clone https://github.com/Subigya111/blogWebApp.git
cd your-repository
composer install
php artisan serve
```
